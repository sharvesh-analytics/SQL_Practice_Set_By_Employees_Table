## 3. Joins (Combining Tables)

### INNER JOIN
Retrieves only the matching records from both tables.

### LEFT JOIN
Returns all records from the left table and matching records from the right table.

### RIGHT JOIN
Returns all records from the right table and matching records from the left table.

### FULL OUTER JOIN
Returns all records from both tables.

# Day 2: Advanced SQL

## 4. Advanced SQL Techniques

### Subqueries

Query written inside another query.

Subqueries can be used in:

- WHERE clause
- SELECT clause
- FROM clause


---

### Common Table Expressions (CTEs)

CTEs use the `WITH` clause to simplify complex queries and improve readability.

#### Uses of CTEs

- Breaking complex queries into smaller parts.
- Improving query readability.
- Performing advanced reporting.
- Data transformation and analysis.
